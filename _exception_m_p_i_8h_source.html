20 //! \brief Assert macro that only throws an exception if expr fails.
21 //! \details If NDEBUG is defined (e.g. cmake's RELEASE or OPTIMIZED mode), do
22 //! nothing, expr is not evaluated. If NDEBUG is not defined, evaluate expr.
23 //! If expr is true, do nothing. If expr is false, throw Exception with
24 //! arguments passed in. The behavior is similar to libc's assert macro, but
25 //! throwing an Exception instead will also generate a nice call-trace and
26 //! will attempt to free memory. This macro should be used to detect
27 //! programmer errors.
28 //! \author J. Bakosi

30 # define AssertMPI(expr, ...) (static_cast<void>(0))

36 //! \brief ErrChkMPI macro that only throws an exception if expr fails.
37 //! \details The behavior of this macro is the same whether NDEBUG is defined or
38 //! not: expr is always evaluated. If expr is true, do nothing. If expr is
39 //! false, throw Exception with arguments passed in. This macro should be
40 //! used to detect user or runtime errors. The main difference compared to
41 //! the vanilla ErrChk macro, defined in Base/Exception.h, is that this macro
42 //! always does an MPI_Allreduce on the outcome of expr. Since MPI_Allreduce
43 //! combines values of err from all MPI ranks and distributes the result back
44 //! to all ranks, the result of expr (err) appear on all ranks, thus if any
45 //! of the ranks had expr false, all will throw. Thus this macro should be
46 //! used to detect user or runtime errors from code sections that are
47 //! executed on multiple MPI ranks. Within asynchrounous Charm++ chares, the
48 //! simpler ErrChk macro suffices.
49 //! \author J. Bakosi
50 #define ErrChkMPI(expr, ...) \
51 { \
52  int err = (expr) ? 0 : 1; \
53  int globalerr; \
54  MPI_Allreduce( &err, &globalerr, 1, MPI_INT, MPI_SUM, MPI_COMM_WORLD ); \
55  if ( globalerr ) Throw( __VA_ARGS__); \
56 }
