Build on macOS

This page describes a macOS build using Homebrew's OpenMPI and clang. MacOS builds are not routinely tested. Proceed at your own risk.

Prerequisites

Charm++'s buildold does not correctly pick up a custom-built MPI installation on macOS. Use Homebrew's OpenMPI instead. Building OpenMPI with GCC on macOS has also been broken since 2022, so use the clang shipped with macOS.

Ensure that the Xcode command-line tools are installed and locate the macOS SDK:

   xcode-select --install
   xcode-select -p
   xcrun --sdk macosx --show-sdk-path
   ls -l "$(xcrun --sdk macosx --show-sdk-path)/usr/lib" | head

Install the required Homebrew packages:

   brew install autoconf automake gcc open-mpi

Install CMake version 3.x, not version 4.x, from https://cmake.org/files/.

Patch the TPLs

Apply the macOS patches manually before configuring the TPL build. Full patches are in Patch file contents

Patch Charm++

The Charm++ patch updates the MPI configuration checks with explicit int return types for their generated main functions. Apply it from the Charm++ source directory:

   cd quinoa-tpl/src/charm
   git apply <charm-macos-patch>

Patch Trilinos

The Trilinos patch adds the sort_option member to the Kokkos sparse-addition handle. Apply it from the Trilinos source directory:

   cd quinoa-tpl/src/trilinos
   git apply <trilinos-macos-patch>

Patch Eigen

The Eigen patch adjusts the transposition product construction. Apply it from the Eigen source directory:

   cd quinoa-tpl/src/eigen
   git apply <eigen-macos-patch>

Build the TPLs

Create a TPL build directory, then configure it with the Homebrew MPI wrappers:

   cd quinoa-tpl
   mkdir build/appleclang-arm64
   cd build/appleclang-arm64

   cmake -DCMAKE_CXX_COMPILER=mpicxx -DCMAKE_C_COMPILER=mpicc \
         -DCMAKE_Fortran_COMPILER=mpif90 -DCMAKE_BUILD_TYPE=Release \
         -DINCITER_ONLY=true -DCMAKE_INSTALL_PREFIX=<tpl-install-dir> ../..

Build Charm++ serially, then build the remaining TPLs in parallel:

   make charm -j1
   make -j8

Build Quinoa

Create a Quinoa build directory. Configure it with the TPL installation directory and Ninja:

   cd quinoa
   mkdir build/appleclang-arm64
   cd build/appleclang-arm64

   cmake -DCMAKE_CXX_COMPILER=mpicxx -DCMAKE_C_COMPILER=mpicc \
         -DCMAKE_BUILD_TYPE=Release \
         -DTPL_DIR=<tpl-install-dir> \
         ../../src

Replace the <tpl-install-dir> value with the path to the corresponding TPL installation on your system, then build:

   make -j8
