2 /*!
3  \file src/DiffEq/MixNumberFractionBeta.h
4  \author J. Bakosi
5  \date Wed 04 May 2016 11:17:03 AM MDT
6  \copyright 2012-2015, Jozsef Bakosi, 2016, Los Alamos National Security, LLC.
7  \brief System of mix number-fraction beta SDEs
8  \details This file implements the time integration of a system of stochastic
9  differential equations (SDEs) with linear drift and quadratic diagonal
10  diffusion, whose invariant is the joint [beta
11  distribution](http://en.wikipedia.org/wiki/Beta_distribution). There are two
12  differences compared to the plain beta SDE (see DiffEq/Beta.h):
13 
14  - First, the parameters, b, and kappa are specified via functions that
15  constrain the beta SDE to be consistent with the turbulent mixing process.
16  In particular, the SDE is made consistent with the no-mix and fully mixed
17  limits. See, e.g., MixNumberFractionBetaCoeffConst::update().
18 
19  - Second, there two additional random variables computed, the same as also
20  computed by the number-fraction beta equation, see also
21  DiffEq/NumberFractionBeta.h.
22 
23  In a nutshell, the equation integrated governs a set of scalars,
24  \f$0\!\le\!X_\alpha\f$, \f$\alpha\!=\!1,\dots,N\f$, as
25  \f[
26  \mathrm{d}X_\alpha(t) = \frac{b_\alpha}{2}\left(S_\alpha - X_\alpha\right)
27  \mathrm{d}t + \sqrt{\kappa_\alpha X_\alpha(1-X_\alpha)}
28  \mathrm{d}W_\alpha(t), \qquad \alpha=1,\dots,N
29  \f]
30  with parameter vectors \f$b_\alpha = \Theta b'_\alpha > 0\f$, \f$
31  \newcommand{\irv}[1]{\langle{#1^2}\rangle} \kappa_\alpha = \kappa' \irv{x} >
32  0\f$, and \f$0 < S_\alpha < 1\f$. This is similar to DiffEq/Beta.h, but the
33  parameters, \f$b\f$ and \f$\kappa\f$ constrained. Here \f$
34  \newcommand{\irv}[1]{\langle{#1^2}\rangle}
35  \newcommand{\irmean}[1]{{\langle{#1}\rangle}} \Theta = 1 - \irv{x} /
36  [ \irmean{X} (1-\irmean{X}) ]\f$. The fluctuation about the mean, \f$
37  \newcommand{\irmean}[1]{{\langle{#1}\rangle}} \irmean{X} \f$, is defined as
38  usual: \f$ \newcommand{\irmean}[1]{{\langle{#1}\rangle}} x = X - \irmean{X}
39  \f$, and \f$b'\f$ and \f$ \kappa'\f$ are user-specified constants. Also,
40  \f$\mathrm{d}W_\alpha(t)\f$ is an isotropic vector-valued
41  [Wiener process](http://en.wikipedia.org/wiki/Wiener_process) with
42  independent increments. The invariant distribution is the joint beta
43  distribution. This system of SDEs consists of N independent equations. For
44  more on the beta SDE, see http://dx.doi.org/10.1080/14685248.2010.510843.
45 
46  Similar to the number-fraction beta SDE (DiffEq/NumberFractionBeta.h), in
47  addition to integrating the above SDE, there are two additional functions
48  of \f$ X_\alpha \f$ are computed as
49  \f[ \begin{align}
50  \rho(X_\alpha) & = \rho_{2\alpha} ( 1 - r'_\alpha X_\alpha ) \\
51  V(X_\alpha) & = \frac{1}{ \rho_{2\alpha} ( 1 - r'_\alpha X_\alpha ) }
52  \end{align} \f]
53  These equations compute the instantaneous mixture density, \f$ \rho \f$, and
54  instantaneous specific volume, \f$ V_\alpha \f$, for equation \f$ \alpha \f$
55  in the system. These quantities are used in binary mixing of
56  variable-density turbulence between two fluids with constant densities, \f$
57  \rho_1, \f$ and \f$ \rho_2 \f$. The additional parameters, \f$ \rho_2 \f$
58  and \f$ r' \f$ are user input parameters and kept constant during
59  integration. Since we compute the above variables, \f$\rho,\f$ and \f$V\f$,
60  and call them mixture density and specific volume, respectively, \f$X\f$,
61  governed by the beta SDE is a number (or mole) fraction.
62 
63  _All of this is unpublished, but will be linked in here once published_.
64 */

143  //! \brief Advance particles according to the system of mix number-fraction
144  //! beta SDEs
145  //! \param[in,out] particles Array of particle properties
146  //! \param[in] stream Thread (or more precisely stream) ID
147  //! \param[in] dt Time step size
148  //! \param[in] moments Map of statistical moments
149  //! \author J. Bakosi
150  void advance( tk::Particles& particles,
151  int stream,
152  tk::real dt,
153  tk::real,
154  const std::map< tk::ctr::Product, tk::real >& moments )
155  {
156  // Update SDE coefficients
157  coeff.update( m_depvar, m_ncomp, moments, m_bprime, m_kprime, m_b, m_k );
158  // Advance particles
159  const auto npar = particles.nunk();
160  for (auto p=decltype(npar){0}; p<npar; ++p) {
161  // Generate Gaussian random numbers with zero mean and unit variance
162  std::vector< tk::real > dW( m_ncomp );
163  m_rng.gaussian( stream, m_ncomp, dW.data() );
164  // Advance all m_ncomp scalars
165  for (ncomp_t i=0; i<m_ncomp; ++i) {
166  tk::real& X = particles( p, i, m_offset );
167  tk::real d = m_k[i] * X * (1.0 - X) * dt;
168  d = (d > 0.0 ? std::sqrt(d) : 0.0);
169  X += 0.5*m_b[i]*(m_S[i] - X)*dt + d*dW[i];
170  // Compute instantaneous values derived from updated X
171  particles( p, m_ncomp+i, m_offset ) = rho( X, i );
172  particles( p, m_ncomp*2+i, m_offset ) = vol( X, i );
173  }
174  }
175  }
