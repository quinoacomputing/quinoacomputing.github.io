28 //! \details This functions is used as an external uniform random number
29 //! generator (i.e., external to TestU01) that is called by the TestU01
30 //! library, hence the required signature and hence the global scope. It is
31 //! templated on a unique integer corresponding to the RNG type enum defined
32 //! by tk::ctr::RNGType. Templating on the id enables the compiler to generate
33 //! a different wrapper for a different RNG facilitating simultaneous calls to
34 //! any or all wrappers as they are unique functions.
35 //! \return Random number generated as a double-precision floating point value
36 //! \author J. Bakosi

40  const auto rng = g_rng.find( id );

43  else
