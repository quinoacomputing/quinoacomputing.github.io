53  //! \brief Constructor: set all defaults.
54  //! \param[in] ctrinfo std::map of control file keywords and their info
55  //! \details Anything not set here is initialized by the compiler using the
56  //! default constructor for the corresponding type. The ctrinfo map
57  //! argument is optional. If not given, it is an empty std::map
58  //! constructed in-place and affects nothing. If given, it contains the
59  //! control file keywords, all of which are moved into the relevant slot
60  //! (tag::ctrinfo). This allows constructing, e.g., a CmdLine object both
61  //! with and without this information in place, which are both used at
62  //! different stages of the execution. For example, because the
63  //! command-line is parsed very early on during runtime while the input
64  //! deck is only parsed much later, the control-file keywords and their
65  //! information (owned by and generated by the input deck and its
66  //! constructor) is not yet available when the CmdLine object is
67  //! constructed. However, during command-line parsing it is still possible
68  //! to request information on a control file keyword, so it must be
69  //! available. The input deck is where all parsed information goes during
70  //! control file parsing and is stored at global scope, see, e.g.,
71  //! walker::g_inputdeck. This global-scope (still namespace-scope), input
72  //! deck object is thus created before command-line parsing. The input
73  //! deck object's constructor (working only on type information, available
74  //! at compile-time, of all the control file keywords) creates a run-time
75  //! map. This is a run-time map, but available before main() starts,
76  //! because it is const and it is initialized as a global-scope map. This
77  //! map is then passed in here as ctrinfo, and its contents inserted into
78  //! the CmdLine object, making the control-file keywords and their info
79  //! available during command-line parsing. Since the input deck stack
80  //! contains a copy of the command-line stack, the command-line stack must
81  //! be possible to be instantiated without passing the ctrinfo map,
82  //! otherwise it would be a mutual dependency.
83  //! \author J. Bakosi
84  CmdLine( tk::ctr::HelpFactory ctrinfo = tk::ctr::HelpFactory() ) {
85  set< tag::io, tag::output >( "out" );
86  set< tag::io, tag::pdf >( "pdf" );
87  set< tag::io, tag::stat >( "stat.txt" );
88  set< tag::virtualization >( 0.0 );
89  set< tag::verbose >( false ); // Quiet output by default
90  // Initialize help: fill from own keywords + add map passed in
91  boost::mpl::for_each< keywords >( tk::ctr::Info( get< tag::cmdinfo >() ) );
92  get< tag::ctrinfo >() = std::move( ctrinfo );
93  }
