4  \author J. Bakosi

7  \brief System of diagonal Ornstein-Uhlenbeck SDEs
8  \details This file implements the time integration of a system of stochastic
9  differential equations (SDEs), with linear drift and constant diagonal
10  diffusion, whose invariant is the joint [normal
11  distribution](http://en.wikipedia.org/wiki/Normal_distribution).
12 
13  In a nutshell, the equation integrated governs a set of scalars,
14  \f$Y_\alpha\f$, \f$\alpha\!=\!1,\dots,N\f$, as
15  \f[
16  \mathrm{d}Y_\alpha(t) = \theta_\alpha\left(\mu_\alpha - Y_\alpha\right)
17  \mathrm{d}t + \sigma_\alpha\mathrm{d}W_\alpha(t), \qquad \alpha=1,\dots,N
18  \f]
19  with parameter vectors \f$\theta_\alpha > 0\f$, \f$\mu_\alpha\f$, and
20  \f$\sigma_\alpha > 0\f$. Here \f$\mathrm{d}W_\alpha(t)\f$ is an isotropic
21  vector-valued [Wiener process](http://en.wikipedia.org/wiki/Wiener_process)
22  with independent increments. The invariant distribution is the joint normal
23  distribution. This system of SDEs consists of N independent equations, each
24  being a single-variate [Ornstein-Uhlenbeck
25  process](http://en.wikipedia.org/wiki/Ornstein%E2%80%93Uhlenbeck_process).
26 
27  From the Fokker-Planck equation, equivalent to the SDE above, the equations
28  governing the means, \f$ \langle Y_\alpha \rangle\f$, are
29  \f[
30  \newcommand{\irmean}[1]{{\langle{#1}\rangle}}
31  \frac{\partial\irmean{Y_\alpha}}{\partial t} =
32  \theta_\alpha\left(\mu_\alpha - \irmean{Y_\alpha}\right)
33  \f]
34  while the equation governing the covariance matrix, \f$ \langle y_\alpha
35  y_\beta \rangle \equiv \left\langle (Y_\alpha - \langle Y_\alpha \rangle)
36  (Y_\beta - \langle Y_\beta\rangle) \right\rangle \f$, is
37  \f[
38  \newcommand{\irmean}[1]{{\langle{#1}\rangle}}
39  \newcommand{\irv}[1]{\langle{#1^2}\rangle}
40  \frac{\partial\irmean{y_\alpha y_\beta}}{\partial t} =
41  -\left(\theta_\alpha+\theta_\beta\right)\irmean{y_\alpha y_\beta} +
42  \left\{ \begin{array}{lr}
43  \sigma_\alpha^2 & \mathrm{for} \quad \alpha = \beta,\\
44  0 & \mathrm{for} \quad \alpha \ne \beta
45  \end{array} \right..
46  \f]
47 */

114  //! \brief Advance particles according to the system of diagonal
115  //! Orsntein-Uhlenbeck SDEs
116  //! \param[in,out] particles Array of particle properties
117  //! \param[in] stream Thread (or more precisely stream) ID
118  //! \param[in] dt Time step size
119  //! \author J. Bakosi
120  void advance( tk::Particles& particles,
121  int stream,
122  tk::real dt,
123  tk::real,
124  const std::map< tk::ctr::Product, tk::real >& )
125  {
126  const auto npar = particles.nunk();
127  for (auto p=decltype(npar){0}; p<npar; ++p) {
128  // Generate Gaussian random numbers with zero mean and unit variance
129  std::vector< tk::real > dW( m_ncomp );
130  m_rng.gaussian( stream, m_ncomp, dW.data() );
131 
132  // Advance all m_ncomp scalars
133  for (ncomp_t i=0; i<m_ncomp; ++i) {
134  tk::real& par = particles( p, i, m_offset );
135  tk::real d = m_sigmasq[i] * dt;
136  d = (d > 0.0 ? std::sqrt(d) : 0.0);
137  par += m_theta[i]*(m_mu[i] - par)*dt + d*dW[i];
138  }
139  }
140  }
