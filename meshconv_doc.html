MeshConv: Mesh file converter

Meshconv is a mesh file converter. It can be used to convert 3D tetrahedron meshes from and to either of the following formats:

  • Gmsh, http://www.geuz.org/gmsh
  • Netgen, http://sourceforge.net/apps/mediawiki/netgen-mesher
  • ExodusII, http://sourceforge.net/projects/exodusii

Similar to the rest of Quinoa, meshconv also uses the Charm++ runtime system, however, meshconv is currently not parallelized.

Help on command-line parameters

As usual, use the -h command-line parameter to get on-screen help from an executable. Example output, exluding Charm++ command-line parameters:

1 $ meshconv -h
2 meshconv Command-line Parameters:
3  -h, --help Display one-liner help on all command-line arguments
4  -H, --helpkw string Display verbose help on a single keyword
5  -i, --input string Specify the input file
6  -o, --output string Specify the output file
7  -v, --verbose Select verbose screen output
