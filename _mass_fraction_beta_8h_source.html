2 /*!
3  \file src/DiffEq/MassFractionBeta.h
4  \author J. Bakosi
5  \date Sat 30 Jan 2016 09:11:35 PM MST
6  \copyright 2012-2016, Jozsef Bakosi.
7  \brief System of mass-fraction beta SDEs
8  \details This file implements the time integration of a system of stochastic
9  differential equations (SDEs) with linear drift and quadratic diagonal
10  diffusion, whose invariant is the joint [beta
11  distribution](http://en.wikipedia.org/wiki/Beta_distribution). The main
12  difference compared to the plain beta SDE (see DiffEq/Beta.h), is that in
13  the mass-fraction beta SDE the dependent variable, there are two
14  additional stochastic variables computed from the beta variables.
15 
16  In a nutshell, the equation integrated governs a set of scalars,
17  \f$0\!\le\!Y_\alpha\f$, \f$\alpha\!=\!1,\dots,N\f$, as
18  \f[
19  \mathrm{d}Y_\alpha(t) = \frac{b_\alpha}{2}\left(S_\alpha - Y_\alpha\right)
20  \mathrm{d}t + \sqrt{\kappa_\alpha Y_\alpha(1-Y_\alpha)}
21  \mathrm{d}W_\alpha(t), \qquad \alpha=1,\dots,N
22  \f]
23  with parameter vectors \f$b_\alpha > 0\f$, \f$\kappa_\alpha > 0\f$, and \f$0
24  < S_\alpha < 1\f$. This is the same as in DiffEq/Beta.h. Here
25  \f$\mathrm{d}W_\alpha(t)\f$ is an isotropic vector-valued [Wiener
26  process](http://en.wikipedia.org/wiki/Wiener_process) with independent
27  increments. The invariant distribution is the joint beta distribution. This
28  system of SDEs consists of N independent equations. For
29  more on the beta SDE, see http://dx.doi.org/10.1080/14685248.2010.510843.
30 
31  In addition to integrating the above SDE, there are two additional functions
32  of \f$ Y_\alpha \f$ are computed as
33  \f[ \begin{align}
34  \rho(Y_\alpha) & = \frac{ \rho_{2\alpha} }{ 1 + r_\alpha Y_\alpha } \\
35  V(Y_\alpha) & = \frac{1}{ \rho(Y_\alpha) }
36  \end{align} \f]
37  These equations compute the instantaneous mixture density, \f$ \rho \f$, and
38  instantaneous specific volume, \f$ V_\alpha \f$, for equation \f$ \alpha \f$
39  in the system. These quantities are used in binary mixing of
40  variable-density turbulence between two fluids with constant densities, \f$
41  \rho_1, \f$ and \f$ \rho_2 \f$. The additional parameters, \f$ \rho_2 \f$
42  and \f$ r' \f$ are user input parameters and kept constant during
43  integration. Since we compute the above variables, \f$\rho,\f$ and \f$V\f$,
44  and call them mixture density and specific volume, respectively, \f$Y\f$,
45  governed by the beta SDE is a mass fraction, hence the name mass-fraction
46  beta.
47 
48  _All of this is unpublished, but will be linked in here once published_.
49 */

115  //! \brief Advance particles according to the system of mass-fraction beta
116  //! SDEs
117  //! \param[inout] particles Array of particle properties
118  //! \param[in] stream Thread (or more precisely stream) ID
119  //! \param[in] dt Time step size
120  //! \param[in] t Physical time
121  //! \param[in] moments Map of statistical moments
122  //! \author J. Bakosi
123  void advance( tk::Particles& particles,
124  int stream,
125  tk::real dt,
126  tk::real t,
127  const std::map< tk::ctr::Product, tk::real >& moments )
128  {
129  // Advance particles
130  const auto npar = particles.nunk();
131  for (auto p=decltype(npar){0}; p<npar; ++p) {
132  // Generate Gaussian random numbers with zero mean and unit variance
133  tk::real dW[m_ncomp];
134  m_rng.gaussian( stream, m_ncomp, dW );
135  // Advance all m_ncomp scalars
136  for (ncomp_t i=0; i<m_ncomp; ++i) {
137  tk::real& Y = particles( p, i, m_offset );
138  tk::real d = m_k[i] * Y * (1.0 - Y) * dt;
139  d = (d > 0.0 ? std::sqrt(d) : 0.0);
140  Y += 0.5*m_b[i]*(m_S[i] - Y)*dt + d*dW[i];
141  // Compute instantaneous values derived from updated Y
142  particles( p, m_ncomp+i, m_offset ) = rho( Y, i );
143  particles( p, m_ncomp*2+i, m_offset ) = vol( Y, i );
144  }
145  }
146  }

165  //! \brief Return density for mass fraction
166  //! \details Functional wrapper around the dependent variable of the beta
167  //! SDE. This function returns the instantaneous density, rho,
168  //! based on the mass fraction, Y, and parameters rho2 and r'.
169  //! \param[in] Y Instantaneous value of the mass fraction, Y
170  //! \param[in] i Index specifying which (of multiple) parameters to use
